# 訂餐管理系統 — 需求規劃 ## 1. 專案目標 建立一個讓班級（或團體）進行日常訂餐的線上系統，取代紙本傳閱、口頭統計與人工對帳。 系統達成的目標： 1. 同學能在截止前完成點餐，並隨時查看自己的訂單。 2. 助教能自動取得訂單統計，並匯出訊息給店家。 3. 餐點送達後，助教能依「姓名＋餐點」清單逐一核對發餐。 4. 同學與助教遇到選擇困難時，能以隨機方式決定店家與餐點。 5. 助教能紀錄每位同學的付款狀態。 6. 多個班級能合併為一張訂單向同一家店訂購，並保留各班獨立的發餐與收款。 7. 同學與助教能對餐廳留下評價與回饋，並以評價高低排序餐廳，作為選店參考。 --- ## 2. 使用者痛點與改善方式 ### 2.1 資訊不透明與菜單管理 | 痛點 | 改善方式 | 對應功能 | |---|---|---| | 菜單取得不易，不知道有哪些餐廳與菜單可選 | 瀏覽菜單、點餐、修改或取消自己的訂單、查看付款狀態、使用隨機選擇 | | 管理者（助教） | 管理餐廳與菜單、開單與收單、查看所有訂單、發餐核對、標記付款、使用隨機選擇、留下助教評語 | | 主辦助教 | 跨班併單中負責建立併單、設定餐廳與統一截止時間，並查看各班合併統計 | | 參與助教 | 加入併單，管理自己班級同學的訂單、發餐與付款 | --- ## 4. 整體流程 ``` 助教開單（選餐廳、設定截止時間） ↓ 同學點餐（可使用隨機選擇） ↓ 截止收單（系統鎖定訂單、自動統計） ↓ 助教匯出訂單文字，傳給店家 ↓ 餐點送達 → 助教使用「發餐核對清單」逐一核對、發餐 ↓ 助教標記付款狀態 → 結案 ``` 跨班併單的流程： ``` 主辦助教建立併單（選餐廳、設定統一截止時間） ↓ 其他班助教加入併單 ↓ 各班同學在自己的班級點餐 ↓ 統一截止 → 系統合併各班統計 → 主辦助教匯出一份訂單給店家 ↓ 餐點送達 → 各班助教以分班核對清單發餐 → 各班助教各自標記付款 ``` --- ## 5. 功能需求 ### 5.1 餐廳與菜單 | ID | 功能 | 說明 | |---|---|---| | M1 | 餐廳清單 | 顯示可選擇的餐廳名稱與聯絡資訊 | | M2 | 菜單品項 | 每個品項包含名稱、價格；助教可新增、修改、停用品項 | | M3 | **助教隨機選店家**：助教開單前，無法決定今天訂哪一家時，在餐廳清單中按下「隨機選店家」，系統抽出一家，助教確認後直接以該店家開單。 - **同學隨機選餐點**：同學進入點餐頁後，無法決定吃什麼時，按下「隨機選餐點」，系統從當日可點品項中抽出一項，同學可重抽、排除或直接採用並加入訂單。 - **隨機結果的限制**：抽取結果僅作為選擇輔助，不會自動送出訂單；同學仍需確認後才完成點餐。 ### MVP 範圍 MVP 包含以下功能，目標是完成「開單 → 點餐 → 統計匯出 → 發餐核對 → 付款標記」的完整流程。 | 類別 | 納入 MVP 的功能 | |---|---| | 菜單 | M1、M2、M3、M4 | | 開單／收單 | O1、O2、O3、O4、O5、O6 | | 點餐 | U1、U2、U3、U4、U5 | | 統計匯出 | S1、S2 | | 發餐核對 | D1、D2、D3、D4、D5、D6 | | 隨機選擇 | R1、R2、R3、R4、R5、R6 | | 付款 | P1、P2、P3 | | 例外通知 | N1、N2 | | 跨班訂單 | X1、X2、X3、X4、X5、X6、X7、X8 | | 評價回饋與店家排序 | V1、V2、V3、V4、V5、V6 | MVP 不包含：線上支付、外送狀態追蹤、低消成團進度條。 --- ## 8. 驗收標準 | 項目 | 驗收標準 | |---|---| | 點餐 | 同學能在截止前完成點餐，且送出前可看到總金額 | | 截止鎖定 | 截止後同學無法新增、修改或取消訂單 | | 統計 | 系統統計的數量與金額，與逐筆訂單加總結果一致 | | 匯出 | 匯出文字可直接複製貼上至 LINE，內容含品項、標籤、數量與總金額 | | 發餐核對 | 清單中每位訂購人的姓名與其所有餐點、數量、標籤皆完整顯示，且與訂單資料一致 | | 發餐勾選 | 勾選「已領取」後狀態即時更新，未領取者可篩選出 | | 隨機選店家 | 抽取結果必定來自啟用中的餐廳清單，且不含被排除的餐廳 | | 隨機選餐點 | 抽取結果必定來自該店家可點且未缺貨的品項，且不含被排除的品項 | | 隨機結果 | 重抽可再次產生結果；採用後帶入開單或點餐頁，但不自動送出訂單 | | 付款 | 助教標記付款狀態後，同學端即時顯示對應狀態 | | 跨班加入 | 其他班助教以連結或代碼加入後，該班同學可在同一張併單中點餐 | | 跨班統計 | 合併統計的各品項數量與金額，等於各班統計加總 | | 跨班截止 | 統一截止時間到達後，所有加入班級同時無法新增、修改或取消訂單 | | 跨班權限 | 參與助教只能查看自己班級的姓名明細與付款狀態；主辦助教可查看各班小計與合併統計 | | 評價 | 同學每人每張訂單只能有一筆評價，評分範圍為 1～5 星 | | 評價顯示 | 餐廳平均星等與評價數，與已送出的評價資料一致 | | 店家排序 | 餐廳清單依平均星等由高到低排列，星等相同時評價數多者在前，無評價者在最後 | | 助教評語 | 助教評語與準時度紀錄顯示於餐廳頁，並標示為助教評語 | --- ## 9. 非功能需求 | 類別 | 要求 | |---|---| | 裝置 | 以手機瀏覽器操作為主，電腦亦可使用 | | 操作 | 同學點餐流程簡單，無需教學即可完成 | | 效能 | 截止前多人同時點餐時，頁面仍可正常使用 | | 資料 | 訂單修改與截止後調整須留下紀錄；個人訂單與付款狀態僅本人與助教可見 | --- ## 10. 資料項目 | 資料 | 主要欄位 | |---|---| | 使用者 | 姓名、角色、所屬班級 | | 班級 | 班級名稱、成員、班級助教 | | 餐廳 | 名稱、聯絡資訊、是否啟用、平均星等、評價數 | | 品項 | 所屬餐廳、名稱、價格、價格更新日期、是否缺貨、是否啟用 | | 訂單（開單） | 餐廳、截止時間、狀態、建立者、是否為併單、主辦班級 | | 訂單明細 | 所屬訂單、訂購人姓名、品項、數量、客製化標籤、小計、是否已領取 | | 付款紀錄 | 所屬訂單、訂購人姓名、應付金額、付款狀態 | | 異動紀錄 | 操作者、動作內容、時間 | | 併單班級 | 所屬訂單、加入的班級、加入時間、參與助教 | | 評價 | 所屬訂單、餐廳、評價者、星等、評語、建立與修改時間 | | 助教評語 | 所屬訂單、餐廳、助教、準時度、評語、時間 |
